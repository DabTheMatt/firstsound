# Polish audio glossary (pl-PL)

FIELD keeps one localization catalog. English is `en`. Polish is `pl`.
The browser stores the choice in `field.uiLocale`. A browser with no saved choice stays in English.

Visible labels stay short when a full Polish word would change the workspace.
The accessible name and the tooltip keep the full term.

Kept as written: EQ, FFT, RMS, LUFS, dB, dBFS, Hz, kHz, Q, LFO, MIDI, WAV, MP3, FLAC, PCM, Hold, 2D, 3D, Log, Lin, Mel. The hearing bands keep SUB and AIR. Polish shorts are BAS, NISKI ŚR., ŚRODEK, WYS. ŚR., WYSOKI.

Theme names stay the product names: Studio Dark, Soft Slate, Warm Paper, Dusk.

A loaded musical sample stays “sample” in most of the existing Polish manual. One PCM frame is “próbka”. The empty waveform says that no audio file is loaded.
